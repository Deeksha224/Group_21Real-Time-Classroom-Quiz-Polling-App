🎮 Real-Time Classroom Quiz & Polling App

Classroom engagement and student participation are critical for effective learning, yet
traditional teaching methods often struggle to maintain attention. Real-time quiz and polling
applications, like Kahoot, gamify learning and increase student involvement, but many
existing solutions lack custom animations, interactive feedback, and seamless multiuser
synchronization.
Your challenge is to build a full-stack real-time quiz and polling platform that enables
instructors to create interactive quizzes and polls, engage students live, and provide instant
visual feedback with animations to make learning fun and effective.________________________________________
🚀 Features

👩‍🏫 Instructor Dashboard
•	Create quizzes and polls
•	Start/stop live sessions
•	Monitor real-time responses
•	View live leaderboard

👨‍🎓 Student Interface
•	Join session via room code
•	Answer quizzes in real-time
•	Get instant correct/incorrect animation feedback
•	Experience interactive transitions and visuals

⚡ Real-Time Sync (WebSockets)
•	Zero-lag updates across all connected users
•	Live score updates
•	Smooth UI transitions
•	Multi-user presence tracking

🎨 Visual Feedback & Animations
•	Animated question transitions
•	Animated feedback (correct/incorrect)
•	Progress bars & timers
•	Fun, classroom-friendly effects

📊 Analytics
•	Question-wise statistics
•	Participation summary
•	Instructor insights

📌 Workflow
1.	Each member develops on their own branch
2.	When a feature is ready → Open a Pull Request to main
3.	Team reviews the PR
4.	Approve → Merge into main
This ensures:
•	No code overwriting
•	Smooth collaboration
•	Easy conflict resolution
•	Organized development flow

▶️ Getting Started
1. Clone the repository
git clone https://github.com/Deeksha224/Real-Time-Classroom-Quiz-Polling-App.git
cd Real-Time-Classroom-Quiz-Polling-App
2. Install dependencies
Frontend:
cd client
npm install
Backend:
cd server
npm install
3. Run the development servers
Frontend:
npm start
Backend:
npm run dev
